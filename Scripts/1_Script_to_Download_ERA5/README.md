# ERA5 Precipitation Download

Downloads hourly ERA5 Mean Total Precipitation Rate and merges monthly files into yearly NetCDF files.

**Script**

```text
Download_ERA5_Precip_Hourly_Monthly_to_Yearly.py
```

**User settings**

```text
START_YEAR
END_YEAR
AREA
GRID
OUTPUT_FOLDER
```

**Run**

```bash
python Download_ERA5_Precip_Hourly_Monthly_to_Yearly.py
```

**Output**

```text
era5_precip_YYYY.nc
```
